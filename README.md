# 抖音下载与口播字幕

这个扩展把抖音视频保存和口播字幕整理放在一起。我的主要需求是拿到可复核的字幕和时间轴，减少看完一条视频后再手工抄口播的步骤。

## 工作方式

页面桥接脚本捕获当前视频信息，后台负责下载，侧边栏显示字幕和处理状态。优先读取平台已有字幕，再整理为可导出的 SRT。

```text
抖音页面 → 当前视频与字幕捕获 → 侧边栏预览 → 视频 / SRT 导出
```

- 页面切换时重新绑定当前视频，避免沿用上一条视频的数据。
- 将捕获、下载和字幕解析拆成独立模块。
- 保留可选的浏览器语音识别模块；默认入口不自动下载语音模型。
- Transformers.js 与 ONNX Runtime 的本地资源及许可证有单独目录。

## 安装与检查

在 `chrome://extensions/` 打开开发者模式，加载本仓库根目录，再刷新抖音页面。

```powershell
node --test tests/*.test.js
```

`manifest.json` 描述扩展权限，`capture-core.js` 负责捕获，`subtitle-core.js` 负责字幕，`sidepanel.js` 负责侧边栏。真实页面的 DOM、字幕和视频链接会随平台更新，需要在自己的账号环境里确认可用范围。第三方运行库归属见 `THIRD_PARTY_NOTICES.md`。
