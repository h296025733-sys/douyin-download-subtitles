# 抖音下载与口播字幕

**在当前视频旁读取素材与平台字幕，预览后导出视频或带时间戳的 SRT。**

整理口播参考时，只有一段文字并不够：需要知道这句话在第几秒，切换视频后也要确认字幕仍属于正在看的作品。再把素材下载与字幕整理拆到不同工具里，很容易失去对应关系。

这个 Chrome MV3 扩展把当前视频捕获、字幕解析、预览和导出放进同一个侧栏。优先使用平台已经提供的字幕；浏览器识别保留为可选路径，默认不会自动下载语音模型。

## 一条视频的工作流程

1. 在抖音网页打开目标视频，等待页面加载相应数据。
2. 打开扩展侧栏，检查当前视频与捕获信息。
3. 优先读取平台字幕或字幕轨道，预览片段与时间轴。
4. 下载当前可取得的视频，或导出对应 SRT。
5. 切换作品后，重新确认视频与字幕绑定，避免沿用上一条结果。

没有平台字幕时不能自动宣称已经识别成功。可选模型路径需要实际准备与运行，真实识别质量也需要对照音频复核。

## 捕获与字幕各自独立

```text
页面侧视频 / 字幕信号
  → 页面桥接与捕获
  → 当前视频信息整理
  → 字幕轨道或内联片段解析
  → 时间轴规范化
  → 侧栏预览
  → 浏览器下载 / SRT 导出
```

`manifest.json` 配置页面侧脚本、内容脚本、背景服务与侧栏。页面桥接负责将页面可见信号带到扩展工作流，核心模块整理数据；侧栏处理显示与用户操作，不独自承担所有解析规则。

| 模块 | 职责 |
| --- | --- |
| [capture-core.js](capture-core.js) | 捕获条目、媒体与字幕信息整理 |
| [subtitle-core.js](subtitle-core.js) | 字幕地址、内联片段、时间轴与 SRT |
| [page-hook.js](page-hook.js) | 页面侧数据信号 |
| [bridge.js](bridge.js) | 页面与扩展之间的桥接 |
| [sidepanel.js](sidepanel.js) | 预览、状态与导出操作 |
| [background.js](background.js) | 扩展后台协调 |

## 字幕处理的细节

### 有时间轴，才能回到画面

字幕核心处理片段起止时间与文本，统一时间戳格式，解析字幕文件和内联数据，再生成 SRT。输出保留时、分、秒与毫秒，方便在剪辑软件中定位。

片段需要规范化，异常时间、空文本和不合适的区间不能直接堆进输出。字幕解析与导出放在可独立测试的核心中，不依赖每次都打开浏览器。

### 轨道选择与视频绑定

平台可能同时提供不同语言、原文与不同格式的字幕轨道。解析层整理候选并按已有规则排序，侧栏还需要检查这些字幕属于当前作品。

页面切换和异步捕获会影响数据归属。已有测试包含绑定与切换相关场景，但真实页面结构改变时仍可能需要更新规则。

### 平台文本与 ASR 分开看

平台文本路径不需要语音模型，浏览器 ASR 则需要运行库、模型下载与推理。项目保留 Transformers.js、ONNX Runtime 的本地资源与许可，不能把库文件存在当作真实模型识别已经通过。

模型耗时、浏览器内存和字幕准确率受素材与硬件影响。专有名词、数字、重叠说话与噪声应特别复核。

## 安装与开发

`manifest.json` 当前声明最低 Chrome 版本为 116。

1. 在 `chrome://extensions/` 开启开发者模式。
2. 加载本仓库根目录。
3. 刷新已打开的抖音网页。
4. 打开侧栏，先确认当前视频信息，再使用字幕或下载入口。

核心测试入口：

```powershell
node --test tests/*.test.js
```

测试包括 [字幕核心](tests/subtitle-core.test.js)、[捕获核心](tests/capture-core.test.js)、[页面 Hook](tests/page-hook.test.js) 和原生提取相关用例。SRT 导出还有往返解析检查，帮助发现格式与时间轴问题。

## 公开范围与已知限制

扩展取得的是当前页面暴露的媒体与文本。平台更新、登录状态、资源过期和字幕缺失都可能影响结果；不能保证每条作品都能下载或取得字幕。

2026-10-07 执行了五个 Node 测试入口文件，以及 JavaScript / PowerShell 语法检查；没有完成真实抖音页面安装、下载与模型推理的端到端验收，详见 [检查记录](docs/verification.md)。

公开版没有个人登录态、运行视频与真实字幕缓存。第三方运行库许可见 [第三方说明](THIRD_PARTY_NOTICES.md)，素材后续使用需要自行确认授权。
